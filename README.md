# Open Enterprise AI Platform

An open platform for building enterprise applications with AI.

## Vision

Enable people who understand their business — even without traditional programming skills — to create, operate, extend and share enterprise software with AI.

## Architecture

DeepSeek Harness
→ Harness Adapter
→ Platform Core
→ Package Runtime
→ Apps / Agents / Skills / Workflows / Connectors

## Package ecosystem

The platform is designed to support third-party:

- Apps
- Agents
- Skills
- Workflows
- Connectors
- Data Providers

These packages can eventually be shared, open-sourced or distributed through a marketplace.
