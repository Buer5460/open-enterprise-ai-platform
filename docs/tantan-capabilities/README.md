# 坦坦科技 · 能力全景与场景方案

基于《坦坦科技能力清单1(1).xlsx》整理的独立静态展示页。不会修改企业平台业务代码、数据库、配置或依赖。

## 使用

下载本目录的 `index.html`，使用较新版本 Chrome、Edge、Safari 或 Firefox 打开。所有样式、矢量示意图、脚本与 143 项能力数据都内嵌于一个 HTML 文件；运行时不需要网络、数据库或 API Key。

页面支持：能力概览、板块占比与原表权重切换、15 个子分类图表、6 组行业方案、143 项全文检索、分类筛选、卡片/表格、原始行号详情、CSV 导出与打印。

## 数据口径

- 主表 `A3:H145` 的序号为 1—143，实际有效条目 **143 项**。
- 机器人及管理平台 **58 项**；视频平台及视频 AI 算法 **63 项**；其他能力 **22 项**。
- 二级分类 **15 类**。机器人与视频合计 121 项，占 84.6%。
- 原“说明”页标注 144 项、其他 23 项，与明细不一致；网页按明细统计，不虚构第 144 项，也不修改源 Excel。
- 40% / 40% / 20% 为原表权重，不是收入占比或技术成熟度。
- 原表能力名称、描述、场景和案例备注均予以保留；案例数据、资质、合作及知识产权声明未独立核验。六组行业方案和商业化建议为分析重组，不代表已上线产品。
- 仅收到此 Excel；其说明页引用的两份 PDF 原材料不在本次分析范围。
